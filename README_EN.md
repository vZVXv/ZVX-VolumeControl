# 🔊 Quick Volume Control — User Guide

A lightweight Windows tool to quickly adjust system volume by holding down a single hotkey and moving your mouse.

---

### 🚀 Quick Start

1. Download **`VolumeControl.exe`**.
2. Double-click the file to run it.
   > **Windows SmartScreen Note:** If Windows displays a "Windows protected your PC" warning, click **"More info"** ➔ **"Run anyway"** (this is a standard warning for unsigned executables).
3. The app will minimize to your system tray (near the clock) and run quietly in the background.

---

### 🎛 How to Use

* **Default Hotkey:** `AppsKey` (the Context Menu key, usually located on the bottom right of your keyboard near `Alt`/`Win` and `Ctrl`).
* **Controls:**
  1. **Press and hold** the assigned hotkey.
  2. While holding the key, **move your mouse**:
     * **Right** ➔ Increase Volume 🔊
     * **Left** ➔ Decrease Volume 🔉
  3. **Release the key** once you set the desired volume.

---

### ⚙️ How to Change the Hotkey

If the default key is inconvenient:
1. Find the program icon in the system tray (bottom-right corner next to the clock).
2. **Right-click** the icon.
3. Select **"Settings (Change Key)"** / **"Настройки (Сменить клавишу)"**.
4. Choose a key from the drop-down menu or type your own (e.g., `F1`, `CapsLock`, `XButton1` for side mouse button, or modifiers like `^Space` for Ctrl+Space).
5. Click **"Save"**.

---

### 🔄 Run Automatically at Windows Startup

To run the program automatically when Windows starts:
1. Press `Win + R` on your keyboard.
2. Type `shell:startup` and hit **Enter** (this opens your Startup folder).
3. Right-click `VolumeControl.exe` ➔ **"Create shortcut"**.
4. Move the newly created shortcut into the opened Startup folder.
